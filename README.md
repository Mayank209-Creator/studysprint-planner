# StudySprint Planner

Here’s a copy-and-paste prompt you can use in an AI app builder or coding assistant:

> **Build a complete, demo-ready web application called “StudySprint” for students.**

>

> **Purpose:** Help students organize their study tasks and track their progress. Make it simple enough for a beginner to explain and demonstrate at a hackathon.

>

> **Features:**

> - A dashboard showing the number of tasks due today, upcoming tasks, and completed tasks.

> - A form to add a task with a title, subject, due date, and priority.

> - A task list where students can mark tasks complete, edit them, or delete them.

> - Filters for all tasks, incomplete tasks, and completed tasks.

> - Save tasks in the browser so they remain after the page is refreshed.

> - Add a few clearly labelled sample tasks so the app looks ready for a live demonstration.

>

> **Design and quality:**

> - Create a clean, modern, student-friendly interface that works on phones and computers.

> - Use clear navigation, readable text, helpful empty states, and visible success or error messages.

> - Make every button and feature work—do not include non-functional placeholders.

> - Do not require a login, paid service, or external API.

> - If you are writing code, use React and provide the complete runnable project plus simple instructions to start it.

>

> **For my presentation, also provide:**

> 1. A short explanation of the problem the app solves and who it is for.

> 2. A one-minute demo script.

> 3. Five likely lecturer questions with simple, honest answers.

> 4. A short explanation of how another student could build a similar app step by step.

**Simple demo plan:** Add a task, show it on the dashboard, mark it complete, filter the list, then refresh the page to show that the task is saved.

If your lecturer asks how the data is stored, explain that this version saves it in the browser on that device; it does not yet sync between devices.
